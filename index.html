論文一 · 問題意識02

它想解決什麼

  • GenAI 有一堆已知的難用之處：prompt 難寫、輸出難評估、工作流難調整
  • 但這些問題各自被研究，缺一個共同的、有認知理論基礎的解釋
  • 作者主張：它們其實是同一件事的不同面向
  • 而 HCI 過去談 metacognition，幾乎只出現在資工教育領域

主張：GenAI 難用不是介面問題，是它要求使用者做大量的後設認知工作。

論文一 · 核心概念03

Metacognition ＝ 監控與調控自己的思考

Monitoring 監控 · 評估自己的思考

self-awareness 自我覺察我這封信到底想傳達什麼？
confidence 信心我有多確定我寫得出對的語氣？

Control 調控 · 引導自己的思考

metacognitive flexibility 策略彈性正式語氣跟新同事不合，該調整
task decomposition 任務拆解先定：我要說明專案狀態並請求回饋

例子取自論文。信心再細分 resolution（能否分辨自己何時判斷得準）與 calibration（整體高估或低估），兩者獨立。

論文一 · 主要論點04

負擔發生在三個地方

下 prompt寫不出好 prompt 常常不是語言問題，是還沒想清楚自己要什麼self-awareness
task decomposition
評估輸出、決定要不要信流暢自信的輸出會抬高你的信心 ── processing fluencyconfidence adjustment
決定什麼交給 AI、怎麼重組流程全篇唯一跨越單次互動的層級self-awareness
metacognitive flexibility

負擔沒有消失，是從「執行任務」轉到「監控自己」。

論文二 · 結果 A（質性編碼）08

批判思考沒有減少，是換了形式

information
verification

查證資訊

從「自己找答案」→「檢查 AI 給的對不對」

response
integration

整合回應

從「自己解問題」→「把輸出接進既有脈絡」

task
stewardship

任務監管

從「自己執行」→「監看整件事有無偏離」

這是質性編碼的結果，不是統計結果。

論文二 · 結果 B（量化迴歸）09

使用者的信心，預測他會不會去檢查

對 GenAI 的信心 ↑
→ 批判思考 ↓

越相信工具，越不檢查

對自身能力的信心 ↑
→ 批判思考 ↑

越相信自己判斷得來，越會去檢查

兩者是獨立的變數。這是統計結果，與結果 A 來自不同分析。

小結15

三句話

  • AI 沒有減少認知負擔，它把負擔從「動手做」換成「監控自己在想什麼」
  • 批判思考沒有消失，而是轉向查證、整合、監管三件事
  • 決定人會不會去檢查的，是信心——越信工具越不查，越信自己越會查
